### Decisões técnicas (ADR)

**Server Component com Prisma direto, sem fetch HTTP interno.** Conforme spec.md §15.3, a homepage consulta `prisma` diretamente — evita round-trip HTTP, melhora LCP e mantém SSR para SEO.

**Animações em ilhas cliente isoladas.** Apenas `RevealOnScroll` e o carrossel de depoimentos são `"use client"`. Hero, grid e banner permanecem Server Components; a revelação ao rolar envolve o conteúdo via `RevealOnScroll` sem tornar a seção inteira cliente.

**3 passos no "Como Funciona" da homepage.** A página dedicada `/como-funciona` detalha 4 etapas completas. A homepage usa versão resumida de 3.

**`ProductCard` nasce aqui, reutilizado pela categoria.** Evitar duplicação; a spec de categoria cria apenas o `ProductGrid`.

**Hero LCP.** Imagem com `priority` e `sizes` corretos; durações de animação 150–400ms `ease-out` para não inflar CLS.

**Query de destaques (corrigida — sem `select` + `include` conflitantes):**
```ts
const [categories, featuredProducts, testimonials] = await Promise.all([
  prisma.category.findMany({ where: { isActive: true }, orderBy: { sortOrder: 'asc' } }),
  prisma.product.findMany({
    where: { isActive: true, isFeatured: true },
    take: 4,
    select: {
      slug: true, name: true, fabric: true,
      images: { where: { isPrimary: true }, take: 1, select: { url: true, altText: true } },
      category: { select: { slug: true, name: true } }
    }
  }),
  prisma.testimonial.findMany({ where: { isActive: true }, orderBy: { sortOrder: 'asc' } }),
])
```
